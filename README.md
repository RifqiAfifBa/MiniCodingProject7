# Expense & Budget Visualizer

Mobile-friendly web app to track daily spending: total balance, transaction history, and spending-by-category pie chart.

Built with **HTML + CSS + Vanilla JavaScript** (no framework, no backend). Data stored in **Local Storage**. Chart via **Chart.js CDN**.

## Run locally

Just open `index.html` in a modern browser (Chrome / Firefox / Edge / Safari). No build step.

## Deploy to GitHub Pages (GitHub Desktop)

1. In GitHub Desktop: File → Add Local Repository → choose this folder.
2. Publish / push to a repo named e.g. `CodingCamp-310826-yourname`.
3. On github.com → repo Settings → Pages → Deploy from branch → `main` / root → Save.
4. Open the published URL.

## Structure

- `index.html`
- `css/style.css` (only CSS file)
- `js/app.js` (only JS file)
- `.kiro/steering/product.md` (Kiro constraints copy)

## Features

- MVP: input form with validation, scrollable transaction list with delete, auto total balance, auto pie chart.
- Optional (all 5): custom categories, monthly summary, sorting, budget-limit highlight, dark/light mode.
